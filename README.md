# Glorious Nails & Spa — demo

Pitch rebuild for [Glorious Nails & Spa](https://gloriousnailsandspa.ca/) (Lansdowne / Glebe).

- Next.js 15 + Tailwind + shadcn-style Button
- Lenis smooth scroll + GSAP ScrollTrigger
- Full-bleed pinned hero — images crossfade one-by-one on scroll
- Pages: Home · Services · Gallery · About · Contact
- Fresha booking CTAs throughout
- Brand plum `#6A1B9A` · blush `#EC5598`

Live: https://adil-044.github.io/glorious-nails-ottawa/
